# Donation handoff

The reader remains unofficial. No SRF acceptance, permission to redistribute
text, or deployment arrangement is established by this repository.

The static gift consists of the source, license/notice, source records, and the
build in `dist/`. It requires no paid hosting, database, or keys. The optional
`companion/` is a separate local Node process for readers who use their own
ChatGPT-authenticated Codex CLI. A recipient can use the static reader alone.

Before a handoff, review [SOURCE_GAPS.md](SOURCE_GAPS.md), verify the text against
permitted source pages, and obtain the recipient's decisions on naming, marks,
hosting, and redistribution. Do not present the generic lotus as an SRF emblem.

Exclude `.env`, `.vercel`, `node_modules`, `artifacts`, personal journal exports,
and local generated artwork from a handoff archive. Git history can contain old
configuration and personal author details; review it before sharing. No history
rewrite or deletion is required or authorized by this checklist.

Current installation, privacy, offline behavior, and optional artwork are
documented in [README.md](../README.md). The old private daily-delivery pipeline
has been removed; historical descriptions of its providers are not current features.
