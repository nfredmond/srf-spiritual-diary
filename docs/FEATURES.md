# Reader features

- Daily reading, explicit unavailable dates, nearest-reading navigation, calendar,
  weekly themes, keyword search, and random available reading.
- Three reading themes, text sizing, favorites, reflections, meditation timer,
  keyboard navigation, and a horizontally scrollable week strip.
- Recoverable drafts, validated backup previews, merge imports, preserved conflict
  versions, and a pre-import recovery backup.
- Local quotation cards that grow to fit the full passage and attribution.
- Production offline cache and user-controlled app updates.
- Optional local Codex artwork, with Astra, ChatGPT authentication, progress,
  cancellation, persistent images, and explicit failure messages.

The dataset remains incomplete. Source evidence and acceptance limitations are
recorded separately in SOURCE_GAPS.md and ACCEPTANCE.md. No Supabase, Gemini,
ComfyUI, scheduled delivery, paid worker, or hosted image provider is included.
